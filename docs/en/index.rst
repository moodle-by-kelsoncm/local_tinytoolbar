Overview - moodle-local_tinytoolbar
====================================

**moodle-local_tinytoolbar** is a Moodle local plugin that enables administrators to manage and customize the toolbar and menus of the **TinyMCE** editor through a visual drag-and-drop interface, without editing PHP code.

Key Features
------------

- **Visual Builder**: Toolbar assembler via drag-and-drop.
- **5 Built-in Presets**: Minimal, Classic, Full, Accessibility, and Custom.
- **Live Preview in JSON**: Real-time validation and iframe preview of the toolbar.
- **Internationalization (i18n)**: Full support for English and Brazilian Portuguese (pt_BR).
- **Privacy API**: Compliant with Moodle privacy guidelines.
