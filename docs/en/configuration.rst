Configuration
=============

Plugin Settings
---------------

1. Go to: **Site administration > Plugins > Local plugins > Tiny Toolbar Configurator**.
2. Check the **Enable Tiny Toolbar Configurator** option.
3. Select one of the presets (e.g. Minimal, Classic, Full) or assemble a custom toolbar via drag-and-drop.
4. Preview changes in real time inside the iframe.
5. Save changes to apply globally across the site's TinyMCE editor.
