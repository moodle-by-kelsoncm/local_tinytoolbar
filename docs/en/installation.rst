Installation
============

Requirements
------------

- **Moodle**: 4.5 or higher (minimum required version `2024042200`)
- **PHP**: 8.1, 8.2, or 8.3
- TinyMCE editor enabled in Moodle.

Installation Methods
--------------------

Via Git Clone
~~~~~~~~~~~~~

1. Access the local plugins folder of your Moodle installation:

   .. code-block:: bash

      cd /path/to/moodle/local

2. Clone the repository naming the folder `tinytoolbar`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/local_tinytoolbar.git tinytoolbar

3. Access **Site administration > Notifications** to complete the database upgrade.
