Instalação
==========

Requisitos
----------

- **Moodle**: 4.5 ou superior (versão mínima exigida `2024042200`)
- **PHP**: 8.1, 8.2 ou 8.3
- Editor TinyMCE ativado no Moodle.

Métodos de Instalação
---------------------

Via Git Clone
~~~~~~~~~~~~~

1. Acesse a pasta de plugins locais da instalação Moodle:

   .. code-block:: bash

      cd /caminho/do/moodle/local

2. Clone o repositório nomeando a pasta como `tinytoolbar`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/local_tinytoolbar.git tinytoolbar

3. Acesse **Administração do site > Notificações** para concluir a atualização de banco de dados.
