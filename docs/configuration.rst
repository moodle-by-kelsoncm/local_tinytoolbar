Configuração
============

Configurações do Plugin
-----------------------

1. Acesse: **Administração do site > Plug-ins > Plugins locais > Tiny Toolbar Configurator**.
2. Marque a opção **Enable Tiny Toolbar Configurator**.
3. Selecione um dos presets (ex: Minimal, Classic, Full) ou monte a barra personalizada via *drag-and-drop*.
4. Visualize o preview em tempo real no iframe.
5. Salve as alterações para aplicar globalmente no editor TinyMCE do site.
